# Hall Sensor 연결부 디버깅 기록

## 1. 문제 현상

Hall Sensor 연결부 납땜 후 디버깅 과정에서 다음 문제가 발생하였다.

- ST-LINK를 통한 MCU 연결 실패
- GDB Server에서 다음 오류 발생
  - `Target no device found`
  - `Error in initializing ST-LINK device`
- 전원 인가 시 MCU 및 전원부에서 비정상적인 발열 발생
- MCU 연결 실패로 Hall Sensor 입력 확인 불가

발열이 확인된 이후 추가적인 전원 인가를 중단하고
전원 및 납땜 상태를 점검하였다.


## 2. 원인 분석

Hall Sensor 연결부는 다음 5개의 신호로 구성되어 있다.

- Hall A
- Hall B
- Hall C
- +5V
- GND

멀티미터를 이용하여 전원부를 점검하였다.

초기 측정 과정에서 5V-GND 사이가 매우 낮은 저항으로 측정되었으며,
납땜부의 불필요한 연결(납땜 브리지) 가능성을 확인하였다.

기존 납을 제거한 후 다시 측정했을 때 정상적인 저항값이 확인되어
PCB 내부 문제가 아닌 납땜부 문제로 판단하였다.


## 3. 원인

Hall Sensor의 5V 및 GND 연결부를 납땜하는 과정에서
인접 패드 사이에 의도하지 않은 전기적 연결이 발생하였다.

이로 인해 전원 인가 시 전원부에 비정상적인 전류가 흐르면서
MCU 및 전원부의 발열이 발생하였고,
MCU가 정상적으로 동작하지 않아 ST-LINK와의 SWD 통신도 실패하였다.


## 4. 해결 과정

1. 보드의 모든 전원을 제거하였다.
2. Hall Sensor 연결부의 기존 납을 제거하였다.
3. 5V-GND 사이의 저항을 다시 측정하였다.
4. 패드 및 배선 사이에 불필요한 연결이 없는 것을 확인하였다.
5. Hall Sensor 5개 배선을 다시 납땜하였다.
6. 전원 인가 전 5V-GND 사이의 저항을 다시 측정하였다.
7. 약 12 kΩ의 저항이 측정되는 것을 확인하였다.
8. ST-LINK를 다시 연결하여 MCU와 정상적으로 통신되는 것을 확인하였다.


## 5. 최종 검증

수정 후 다음 항목을 확인하였다.

- [x] 5V-GND 직접 단락 없음
- [x] MCU 비정상 발열 없음
- [x] 전원부 비정상 발열 없음
- [x] ST-LINK 정상 연결
- [x] MCU 디버깅 정상 동작
- [x] Hall A 입력 확인
- [x] Hall B 입력 확인
- [x] Hall C 입력 확인


## 6. 개선 사항

이번 문제를 통해 하드웨어 연결 변경 후
바로 전원을 인가하기 전에 전원 계통을 먼저 점검할 필요성을 확인하였다.

향후 다음 순서로 하드웨어 Bring-up을 진행한다.

1. 육안으로 납땜 상태 확인
2. 전원-GND 사이 저항 측정
3. 인접 패드 사이 단락 여부 확인
4. 전원 인가
5. 전원 레일 전압 및 발열 확인
6. MCU 디버거 연결 확인
7. 주변장치 입력/출력 검증
